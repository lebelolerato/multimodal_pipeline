# Dataset Information

This project uses the Fakeddit multimodal dataset.

- **Source:** https://github.com/entitize/fakeddit
- **Data folders:** train/, validate/, test/
- **Metadata files:** fakeddit_train.tsv, fakeddit_validate.tsv, fakeddit_test.tsv

The dataset is not included in this repository due to size constraints.
To use the data, place the files in the `data/` folder before running the pipeline.
